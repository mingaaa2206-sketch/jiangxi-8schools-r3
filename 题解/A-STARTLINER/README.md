# A. STARTLINER · 题解

> 题目：[`题面/A-STARTLINER.md`](../../题面/)

## 思路

签到题。题目没有输入，直接输出一行 `Make UP Future!`（注意大小写、空格和英文感叹号，行末不要多空格）。

代码里的 `scanf("%d",&n)` 其实可以删掉——题目明确没有输入，读不到东西也不影响结果，写上只是习惯性地有个"读入"动作。

## 复杂度

时间 O(1)，空间 O(1)。

## 代码

完整源码见 [`main.c`](./main.c)。

```c
#include<stdio.h>
int main()
{
    int n;
    scanf("%d",&n);
    printf("Make UP Future!");
    return 0;
}
```

## 备注

本题唯一的坑是**格式**：多一个空格、少一个感叹号、或者在字符串后面多打一个换行之外的内容，都是 WA。
