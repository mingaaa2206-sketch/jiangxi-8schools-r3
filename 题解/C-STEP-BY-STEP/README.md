# C. STEP BY STEP · 题解

> 题目：[`题面/C-STEP-BY-STEP.md`](../../题面/)

## 思路

本质是**不出现 0 的"下一个数"**，可以看成 9 进制意义下的 +1。

从字符串末尾往前找第一个不是 `'9'` 的位置 `i`：

- 找到了：把 `s[i]` 加一，它右边的所有位都变成 `'1'`（因为不能是 0，最小合法数字就是 1）。
  例：`19` → `'1'` 变 `'2'`，后面变 `'1'` → `21`；`199` → `211`。
- 全串都是 `'9'`：说明要进位到新的位数，答案是 `len+1` 个 `'1'`。
  例：`9` → `11`，`99` → `111`。

因为 k ≤ 10^16，最多 17 位，用字符串处理比整数进位更省事，也天然避开溢出。

## 复杂度

时间 O(位数)，空间 O(1)。

## 代码

完整源码见 [`main.c`](./main.c)。

```c
#include<stdio.h>
#include<string.h>
int main()
{
    int t;
    scanf("%d",&t);

    while(t--)
    {
        char s[40];
        scanf("%s",s);

        int len=strlen(s);

        int i=len-1;

        while(i>=0&&s[i]=='9')
        {
            i--;
        }

        if(i>=0)
        {
            s[i]++;

            for(int j=i+1;j<len;j++)
            {
                s[j]='1';
            }

            printf("%s\n",s);
        }
        else
        {
            for(int j=0;j<=len;j++)
            {
                s[j]='1';
            }
            s[len+1]='\0';

            printf("%s\n",s);
        }
    }

    return 0;
}
```

## 备注

注意 `s[i]++` 只会发生在 `'0'`~`'8'` 上（`'9'` 都被跳过了），所以不会出现 `'9'+1` 变字符 `':'` 的越界情况。
