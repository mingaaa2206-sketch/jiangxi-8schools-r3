# G. Viyella's Tears · 题解

> 题目：[`题面/G-Viyella's-Tears.md`](../../题面/)

## 思路

线性 DP。约束只有一条：**不能连续跳过两个靶子**。

设：

- `dp[i][0]`：处理完前 i 个靶子，且**第 i 个射了**时的最大得分；
- `dp[i][1]`：处理完前 i 个靶子，且**第 i 个跳过了**时的最大得分。

转移：

- 射第 i 个：前一个射或跳都可以，`dp[i][0] = max(dp[i-1][0], dp[i-1][1]) + a[i]`；
- 跳第 i 个：前一个必须射（否则连续跳两个就输了），`dp[i][1] = dp[i-1][0]`。

初值：`dp[1][0] = a[1]`，`dp[1][1] = 0`（第一个可以跳，题目允许跳过单个靶子）。

答案：`max(dp[n][0], dp[n][1])`。

因为 a_i 可能为负，全程用最小值/负无穷初始化也可以，但这里直接按两种状态转移就不需要特判。答案可能为负，用 `long long`。

## 复杂度

时间 O(n)，空间 O(n)（可滚动数组优化到 O(1)）。

## 代码

完整源码见 [`main.c`](./main.c)。

```c
#include<stdio.h>

long long dp[100005][2];
long long a[100005];

int main()
{
    int n;
    scanf("%d",&n);

    for(int i=1;i<=n;i++)
    {
        scanf("%lld",&a[i]);
    }

    dp[1][0]=a[1];
    dp[1][1]=0;

    for(int i=2;i<=n;i++)
    {
        if(dp[i-1][0]>dp[i-1][1])
            dp[i][0]=dp[i-1][0]+a[i];
        else
            dp[i][0]=dp[i-1][1]+a[i];

        dp[i][1]=dp[i-1][0];
    }

    if(dp[n][0]>dp[n][1])
        printf("%lld\n",dp[n][0]);
    else
        printf("%lld\n",dp[n][1]);

    return 0;
}
```

## 备注

注意 n = 1 时循环不执行，直接输出 `a[1]`，是正确答案（射或不射取大，`dp[1][1]=0` 相当于不射得 0 分）。
