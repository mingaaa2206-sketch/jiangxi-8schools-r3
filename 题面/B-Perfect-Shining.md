# B. Perfect Shining!

> 第 3 届八校入门赛 · Problem B ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

列车驶出站台，窗外的风景飞快向后退去。星咲明里打开平板电脑，玩起了一个「数字卡片」小游戏——指尖轻点，卡片上的数字闪着微光。这一次，她遇到了一个谜题，转头向你求助。

屏幕上出现了两个正整数 a 和 b。星咲明里需要将这两个数的十进制表示以任意顺序首尾相接，得到一个新的数。新数越大，游戏触发「完美闪耀」的概率也就越大。例如，若 a=12、b=34，则可能得到的新数为 1234 或 3412。

请你帮星咲明里求出按上述方式能得到的最大的新数。

## 输入格式

一行两个正整数 a 和 b，以空格分隔。

## 输出格式

一行一个整数，表示将 a 和 b 的十进制表示以任意顺序首尾相接后，能得到的最大的数。

## 样例

### 样例 #1

输入：

```text
12 34
```

输出：

```text
3412
```

### 样例 #2

输入：

```text
62 135
```

输出：

```text
62135
```

## 说明 / 提示

对于全部数据，保证 1 ≤ a, b ≤ 9999，即 a、b 均为不含前导零的正整数。

样例 1：两种拼接为 1234 与 3412，最大为 3412；样例 2：两种拼接为 62135 与 13562，最大为 62135。
