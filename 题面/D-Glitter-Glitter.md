# D. Glitter-Glitter

> 第 3 届八校入门赛 · Problem D ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

场馆到了。馆内灯火通明，荧光棒的碎光自人海升起又落下——Glitter, Glitter。为了向场馆报备到场人数，星咲明里需要弄清内场和外场各有多少人。

演唱会的内场是一个以 (a, b) 为圆心、以 r 为半径的圆。这场演唱会有 n 位观众，第 i 位观众的座位位于 (x_i, y_i)。

如果一位观众的座位在圆内或圆上，则这位观众位于内场；否则，这位观众属于外场。

请你求出位于内场的观众人数。

## 输入格式

第一行四个整数 n, a, b, r，分别表示观众人数、圆心的横纵坐标与半径。

接下来 n 行，每行两个整数 x_i, y_i，表示第 i 位观众的座位坐标。

## 输出格式

一行一个整数，表示位于内场的观众人数。

## 样例


输入：

```text
3 0 0 5
1 1
3 4
10 10
```

输出：

```text
2
```

## 说明 / 提示

对于全部数据，保证所有输入均为整数，且 1 ≤ n ≤ 10^5，-1000 ≤ a, b ≤ 1000，0 ≤ r ≤ 1000，-1000 ≤ x_i, y_i ≤ 1000。

样例中，点 (3, 4) 到圆心的距离平方为 3² + 4² = 25，恰等于半径平方 r² = 25，即该点在圆上，属于内场。
