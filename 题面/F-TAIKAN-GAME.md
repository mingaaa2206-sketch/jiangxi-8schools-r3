# F. TAIKAN GAME

> 第 3 届八校入门赛 · Problem F ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

买完拼图，星咲明里上了楼——楼上是场馆的街机厅，霓虹闪烁，正是体感游戏的天下。转过街机，她正好撞见同样来玩的藤泽柚子。两人对一个迷宫游戏很感兴趣。她们二人合作，披荆斩棘，通过了很多关卡。

星咲明里凭借自己高超的游戏技巧，成功来到了接近终点的位置，马上就要通关了。但是此时，星咲明里手中的剑已经磨损，藤泽柚子决定给她换一把新的剑。

要想走出这个迷宫，在接近终点的一段路程，玩家需要经历一个具有 n 只怪物的长廊，玩家需要使用手中的剑，依次和这些怪物进行遭遇战。

藤泽柚子给星咲明里的剑有它自己的攻击力 k。为了给星咲明里一个高难度的挑战，藤泽柚子希望星咲明里能够通关的前提下，这把剑的攻击力尽可能低。

每一只怪物都有自己的攻击力。星咲明里每经过一个怪物，如果她手中的剑的攻击力严格大于怪物的攻击力，星咲明里就可以挥动自己手中的剑，杀死这只怪物，此时自己的剑的攻击力可以增加这只怪物的攻击力。否则跳过这只怪物，什么都不发生。

当星咲明里经过最后一只怪物时，她手中的剑的攻击力至少为 x 时，游戏通关，否则游戏失败。

请你帮藤泽柚子求出这把剑的初始攻击力的最小值，以让星咲明里可以通关游戏。

## 输入格式

第一行，n 和 x，表示怪物的数量和游戏通关需要的剑的最少攻击力。

第二行 a_1, a_2, …, a_n，分别代表每只怪物的攻击力。

## 输出格式

一行一个数字，代表藤泽柚子给星咲明里的剑的攻击力的最小可行值。

## 样例


输入：

```text
3 6
5 3 1
```

输出：

```text
4
```

## 说明 / 提示

对于全部数据，保证 1 ≤ n ≤ 10^5，1 ≤ x ≤ 10^5，1 ≤ a_i ≤ 10^5，k ≤ 10^5。

样例中，初始攻击力为 4 的剑依次经过三只怪物：4 < 5，跳过第一只；4 > 3，击杀第二只，攻击力增至 7；7 > 1，击杀第三只，攻击力增至 8。最终 8 ≥ x = 6，游戏通关。若初始攻击力为 3，则前两只怪物均无法击杀，仅击杀第三只后攻击力为 4 < 6，游戏失败。故最小的可行初始攻击力为 4。
