# H. Viyella's Scream

> 第 3 届八校入门赛 · Problem H ｜ 时间 / 内存限制：1 s / 512 MB / Special Judge

## 题目描述

离场前，星咲明里在心里为这一天呐喊了一声——为舞台，为唱进心底的那些歌。她想把这座城市留作纪念，于是决定画下一张它的地图。

她希望这张地图是一个仙人掌图：一个无自环的连通图，且每条边至多出现在一个简单回路中。允许重边——连接相同两端点的两条边构成一个长度为 2 的简单回路。

她要求这张图的生成树数量恰好为 k，并且在所有满足条件的图中，这张图的结点数要尽可能少。

请你帮助她画出这个图。

## 输入格式

一行一个正整数 k，表示要求的生成树数量。

## 输出格式

第一行两个整数 n 和 m，分别表示你构造的图的结点数与边数。

接下来 m 行，每行两个整数 u, v（1 ≤ u, v ≤ n，u ≠ v），表示一条连接结点 u 与结点 v 的无向边。允许重边，不允许自环。

## 样例


输入：

```text
4
```

输出：

```text
3 4
1 2
1 2
2 3
2 3
```

## 说明 / 提示

对于全部数据，保证 1 ≤ k ≤ 10^6。对于范围内的任何 k，均存在满足条件的构造方案。

生成树：连通图的生成树是包含其全部结点、且恰有 n-1 条边的树；生成树数量指不同的生成树的个数。

样例中，结点 1, 2 之间的两条重边构成一个二元环，生成树可以选择其中任意一条边；结点 2, 3 之间同理。由乘法原理，生成树数量为 2 × 2 = 4。可以证明，不存在结点数更少的方案（2 个结点时至多构成 1 个二元环，生成树数量至多为 2）。

判定（Special Judge）：评测程序将校验你输出的图是否满足——连通、无自环、每条边至多属于一个简单回路（仙人掌）、生成树数量恰为 k、结点数等于理论最小值。全部满足即判定通过。
