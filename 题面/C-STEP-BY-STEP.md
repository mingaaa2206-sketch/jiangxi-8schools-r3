# C. STEP BY STEP

> 第 3 届八校入门赛 · Problem C ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

到站了。星咲明里跳下列车，朝演唱会场馆的方向走去——一步，又一步，直到目的地。

她嫌普通的走路太无聊，于是给脚下的路加了点趣味。地上从左到右铺着无穷多块地砖，第 1 块地砖编号为 1，第 2 块编号为 2，以此类推，第 k 块编号为 k。

星咲明里向前行走时，只会踏上编号的十进制表示中不含数字 0 的地砖。例如，她会踏上第 9 块之后踏上第 11 块，跳过第 10 块。

现在，给定她当前所在的地砖编号 k（保证 k 的十进制表示不含数字 0），你需要求出她将会踏上的下一块地砖的编号。

## 输入格式

第一行一个正整数 T，表示测试数据的组数。

接下来 T 行，每行一个正整数 k，表示星咲明里当前所在的地砖编号。

## 输出格式

对每组测试数据，输出一行一个整数，表示星咲明里下一块将会踏上的地砖编号。

## 样例


输入：

```text
3
8
19
99
```

输出：

```text
9
21
111
```

## 说明 / 提示

对于全部数据，保证 1 ≤ T ≤ 1000，1 ≤ k ≤ 10^16，且 k 的十进制表示中不含数字 0。

8 的下一块是 9；19 的下一块跳过含 0 的 20，为 21；99 的下一块跳过 100，为 111。
