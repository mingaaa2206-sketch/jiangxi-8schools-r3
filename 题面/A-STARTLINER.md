# A. STARTLINER

> 第 3 届八校入门赛 · Problem A ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

期待了一整个学期的旅行终于成行。清晨的站台上，星咲明里、藤泽柚子和三角葵背起行囊，踏出了旅程的第一步——STARTLINER，就此发车。

前路未必一帆风顺，路上还有许多问题等着她们。现在，你将成为她们的智囊团，帮她们一一化解。

出发之前，三个人邀你一起喊出此行的口号：塑造未来！

本题你的任务是输出一行，包含字符串 `Make UP Future!`。除此之外，不要输出任何多余的内容。

## 输入格式

本题无输入。

## 输出格式

输出一行一个字符串 `Make UP Future!`。注意大小写和空格，以及英文标点。

## 样例


输入：

```text
(no input)
```

输出：

```text
Make UP Future!
```

## 说明 / 提示

字符串区分大小写，感叹号为英文标点，请原样输出，不要有多余字符（包括行末多余空格）。
