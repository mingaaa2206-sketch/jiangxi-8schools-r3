# G. Viyella's Tears

> 第 3 届八校入门赛 · Problem G ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

体感游戏玩得尽兴，藤泽柚子心满意足地先走了；星咲明里却觉得还差了点什么，眼角微微发热——大概是刚才的舞台太动人了。为了整理心情，她走进了场馆另一侧的射箭体验馆。

体验馆的活动规则如下：从左到右共有 n 个靶子，第 i 个靶子的分值为 a_i（分值可能为负）。星咲明里从起点出发，从左到右依次经过每个靶子，经过每个靶子时，必须选择以下两种操作之一：

- 向这个靶子射箭，获得 a_i 分；
- 跳过这个靶子，不射箭，不获得分数。

注意：如果她在整个过程中连续跳过两个靶子，就会立即输掉游戏。

请你在星咲明里不输掉游戏的前提下，求出她最多可以获得多少分。

## 输入格式

第一行一个正整数 n，表示靶子的个数。

第二行 n 个整数 a_1, a_2, …, a_n，以空格分隔，表示每个靶子的分值。

## 输出格式

一行一个整数，表示她能获得的最大得分。

## 样例


输入：

```text
5
1 2 -1 -2 3
```

输出：

```text
5
```

## 说明 / 提示

对于全部数据，保证 1 ≤ n ≤ 10^5，|a_i| ≤ 10^5。

样例中，若跳过 -1 和 -2 两个靶子则连续跳过两个，会输掉游戏。最优方案为射箭获得 1, 2, -1, 3 四个靶子的分值、跳过 -2，得分为 1 + 2 + (-1) + 3 = 5。

跳过靶子不获得分数；允许跳过单个靶子（包括所有靶子中只剩一个时），因此答案可能为 0，也可能是负数。
