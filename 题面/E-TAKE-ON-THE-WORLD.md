# E. TAKE ON THE WORLD

> 第 3 届八校入门赛 · Problem E ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

演唱会落幕。场馆一层的纪念品超市里，星咲明里淘到了一款拼图玩具——她想把它带回家，把今天的星光一片一片拼进日常。

这款拼图的盘面铺设在由单位等边三角形组成的三角网格上，盘面的规模为 n。规模为 1, 2, 3, 4 的盘面见原题册第 6 页「插图 1」。

盘面是一个上下对称的扁六边形（n = 1 时退化为一个菱形）：上、下两条水平边各由 n-1 段单位线段组成，左右两侧各由两条斜向内的单位线段围出尖角；整个盘面恰好由 4n-2 个单位等边三角形组成。

对于规模为 n+1 的盘面，可以看作在规模为 n 的盘面右侧再拼接如原题册「插图 2」所示的图形（由 4 个单位等边三角形组成，与原盘面在右侧相接，整体仍为一个更大的扁六边形）；而这种拼图游戏的图块只有一种，即「插图 3」。

图块由两个共有一条边的单位等边三角形拼成，外形是一个边长等于单位三角形边长的菱形（内角依次为 60°、120°、60°、120°）。图块可以任意旋转与翻转。

你的任务是用若干个图块不重叠地铺满整个盘面，使得每个单位等边三角形恰好被一个图块覆盖。

你需要输出铺法的种类数。两种铺法不同，当且仅当存在某个图块的覆盖位置不同；同一铺法中图块之间的顺序差异不计入（所有图块完全等价）。

## 输入格式

一行一个正整数 n，表示拼图盘面的规模。

## 输出格式

一行一个整数，表示规模为 n 的盘面的铺法种类数。

## 样例


输入：

```text
2
```

输出：

```text
2
```

## 说明 / 提示

对于全部数据，保证 1 ≤ n ≤ 10^5。

样例中 n = 2，盘面为由 6 个单位等边三角形组成的正六边形，恰有 2 种铺法。
