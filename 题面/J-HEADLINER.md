# J. HEADLINER

> 第 3 届八校入门赛 · Problem J ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

Let's Keep Singing at Any Time!

旅程结束，星咲明里回到了熟悉的地方——她的十六位伙伴早已等在那里。为了庆祝归来，大家准备来一场大合唱；而今天的主角，自然是她这位 HEADLINER。

这场大合唱共有 n 段。同一支队伍的成员互不相同，但不同段之间可能有相同的歌手重复登台。请你统计参与这场大合唱的不同歌手的总人数。

## 输入格式

第一行一个正整数 n，表示合唱的段数。

接下来依次描述 n 段：每段第一行一个正整数 k，表示这一段的歌手数量；第二行 k 个用空格分隔的字符串，表示演唱这一段的歌手的名称。

## 输出格式

一行一个整数，表示参与大合唱的不同歌手总数。

## 样例


输入：

```text
3
2
akari yuzu
2
akari aoi
2
yuzu aoi
```

输出：

```text
3
```

## 说明 / 提示

对于全部数据，保证 1 ≤ n ≤ 10^5，1 ≤ k，所有段的 k 之和不超过 10^5；歌手名称仅由小写英文字母组成，长度不超过 10；歌手名称完全相同（区分大小写）即视为同一歌手。

样例中共有 akari、yuzu、aoi 三位歌手，各演唱了两段，因此不同歌手总数为 3。
