# I. μ3

> 第 3 届八校入门赛 · Problem I ｜ 时间 / 内存限制：1 s / 256 MB

## 题目描述

归程的列车上，窗外的风景缓缓倒退，星咲明里闭上眼，开始回忆这场旅程。

这一天的记忆像铁轨一样在脑海里延伸、分岔。她把它们排成一排，从左到右共有 n 个回忆。初始时，她的满意度为 0。她从区间 [1, n] 开始，按如下递归过程「回忆」一个区间 [l, r]：

1. 计算中点位置 m = floor((l + r) / 2)；
2. 若区间长度 (r - l + 1) 为偶数，则将区间划分为 [l, m] 与 [m+1, r] 两个子区间，分别继续回忆；
3. 若区间长度为奇数，则她将珍藏第 m 个回忆，满意度增加 m；随后将区间划分为 [l, m-1] 与 [m+1, r] 两个子区间，分别继续回忆（当 l = r 时，两个子区间均为空，不再继续）。

星咲明里有一个回忆长度阈值 k：任何长度严格小于 k 的区间她都不会回忆。不回忆的区间不产生满意度，也不会再被划分。

请你求出整个递归过程完全结束后，她的满意度。

## 输入格式

第一行一个正整数 T，表示测试数据的组数。

接下来 T 行，每行两个正整数 n, k，以空格分隔，含义如题面所述。

## 输出格式

对每组测试数据，输出一行一个整数，表示最终的满意度。

## 样例


输入：

```text
6
7 2
11 3
55 13
5801 6
8919 64
8765432 1
```

输出：

```text
12
18
196
1975581
958900
38416403456028
```

## 说明 / 提示

对于全部数据，保证 1 ≤ T ≤ 10^5，1 ≤ k ≤ n ≤ 2 × 10^9。

以第一组数据 n = 7, k = 2 为例：回忆 [1, 7]（长度 7，奇数），珍藏第 4 个回忆，满意度为 4；随后划分 [1, 3] 与 [5, 7] 继续回忆——[1, 3] 珍藏第 2 个，[5, 7] 珍藏第 6 个；再划分出的四个单点区间长度均为 1，严格小于 k = 2，不再回忆。总满意度为 4 + 2 + 6 = 12。
